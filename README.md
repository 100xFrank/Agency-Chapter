# Chapter — independent agency website design

**Live preview:** https://100xfrank.github.io/Agency-Chapter/

**Repository:** https://github.com/100xFrank/Agency-Chapter

This repository contains the complete editable Chapter website. Changes here do not change Signal, Chapter, Framework in any other repository, or NEXTUP. The original three-design comparison remains at https://100xfrank.github.io/Agency-Website-Previews/.

## Edit on your main PC

In Codex choose **Clone repository** and paste the repository URL above, or open this repository through GitHub's green Code button and clone it with your normal Git tools. Open each design in its own folder. Tell Codex: “Read AGENTS.md. Work only on this Chapter repository.”

- content.js: agency name, services, process, proposed options, portfolio briefs and FAQs.
- app.js: headlines, sections and form interaction.
- style.css: visual styling and responsive layouts.
- site.config.js: the selected Chapter direction; no external/shared configuration.
- assets/: original concept imagery.

GitHub Pages publishes main from the repository root. **Commit and push changes to main in THIS repository to update THIS website.** No manual build step is required for GitHub Pages; npm run build is an optional static export.

## Local preview and checks

Node.js 22+ is required for local serving/testing. No packages to install. Run npm start (or node server.mjs), then open http://127.0.0.1:4194/. Each design uses a different local port so you may run all three together. Run npm test and npm run build after relevant edits.

## Concept and privacy status

This is a public design preview. Studio / Name is a working name. No prices or real client relationships are established. Portfolio items are planned concept briefs, not completed websites or endorsements. Contact forms validate and simulate pending, success, failure and retry without sending/storing enquiries or booking appointments. Use fictional test details. Changing a mode flag does not implement live delivery. No analytics or external fonts are installed. Noindex metadata is included but is not an access restriction.

The editorial still-life image is original generated concept photography, not an actual office. Device/browser studies and the placeholder mark are original HTML/CSS/SVG. Typography uses system fonts.
