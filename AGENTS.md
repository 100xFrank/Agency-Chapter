# Chapter agency website preview

This is one independently editable agency design. Preserve its Chapter direction. Edit content.js for business content, app.js for page composition, and style.css for design. site.config.js selects only this design.

The owner requested a separate public GitHub repository and preview URL for this design. No file or remote configuration is shared with the other two standalone repositories. Do not change them or NEXTUP. GitHub Pages serves main at the repository root; pushes to main update only this site.

The agency name is a working placeholder. No final prices, contact details, real clients or commercial claims were provided. The three portfolio graphics are planned concepts, not delivered client work. Forms must remain demonstrable, validated, and explicitly no-delivery unless a real server integration and recipient are separately supplied and tested. Noindex metadata is not access control. Never add secrets or private project notes to this public repository.

Run npm test and npm run build, then check relevant page interactions. No dependency installation is needed.
